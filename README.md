Este é o repositório do meu portfólio pessoal. Um espaço desenvolvido com uma estética moderna **cyberpunk/synthwave** para centralizar meus projetos, habilidades, certificados e canais de contato.

---

# 📱 Sobre o Projeto

O objetivo deste projeto foi criar uma vitrine interativa e responsiva para minha jornada como estudante de **Ciências da Computação**.

O design conta com:

- Animações fluidas
- Efeitos neon
- Flicker cyberpunk
- Background dinâmico
- Interface moderna e responsiva

Tudo isso refletindo minha paixão por tecnologia, programação e cultura geek.

# 📦 Como Executar o Projeto Localmente

## 1️⃣ Clone o Repositório

```bash

```

---

## 2️⃣ Acesse a Pasta do Projeto

```bash
cd Seu-Repositorio
```

---

## 3️⃣ Execute o Projeto

Abra o arquivo:

```bash
index.html
```

ou utilize a extensão **Live Server** no VS Code.
